♠ Full House

A screen-scraping poker assistant for friendly, no-money games. Runs entirely in your browser — nothing is sent to a server. This is a pot-odds/equity heuristic, not a GTO solver — see the repo README for what it is and isn't before you trust it. Consider telling your group you're using it.

1. Share your screen

Pick the window or tab showing your poker table.

2. Calibrate table regions

One-time per browser window size/zoom/theme. Redo this if any of those change.

3. Build card templates

One-time (reusable across sessions unless the table theme changes). Show each of the 52 cards in the hero-card-1 region.

4. Run it

Opens a floating always-on-top recommendation window in Chrome/Edge (falls back to an in-page panel in other browsers).
